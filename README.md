# Colab Demo

Beginner-friendly notebooks for trying Python and OpenAI in Google Colab.

## Notebooks

- [hello_colab.ipynb](hello_colab.ipynb) shows a greeting and simple functions.
- [creative_ideas.ipynb](creative_ideas.ipynb) asks for an everyday object and uses the OpenAI Responses API to suggest one unusual, practical use.

## Run the creative ideas notebook

Open `creative_ideas.ipynb` in Google Colab and run the cells from top to bottom. The first code cell installs the OpenAI Python SDK. The next cell asks for an OpenAI API key using a hidden prompt, then asks for an everyday object.

Enter your API key only in the hidden runtime prompt. Do not paste it into notebook source code or save it in a cell. The notebook is saved without outputs or credentials.
